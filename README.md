# Clothing Similarity Search

A computer vision application that finds visually similar clothing items using image embeddings and similarity search.

## Goals

- Learn image embedding techniques
- Experiment with CLIP-based image representations
- Build an image similarity search system
- Learn vector databases and similarity search
- Develop an API for image-based queries
- Build a web interface for uploading and searching images

## Probable Tech Stack

- Python
- PyTorch
- CLIP / OpenCLIP (?)
- FastAPI
- PostgreSQL
- pgvector (?)
- React
- TypeScript
- Docker
